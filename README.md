# 베타로그 (BetaLog)

클라이머를 위한 **리플레이 카메라**와 **행보드 타이머** 앱이에요.

- **리플레이**: 카메라를 켜두면 최근 2분을 기억했다가, 버튼을 누른 순간부터 거꾸로 1분 / 1분 30초 / 2분을 골라 클립으로 남겨요. 배율·화질(최대 4K) 조절, 타이머 탭에 가도 녹화는 계속돼요
- **폰 카메라로 찍기**: 아이폰 기본 카메라 화질 그대로 찍고, 끝에서부터 1분 / 1분 30초 / 2분만 남겨요. 다시 인코딩하지 않아 화질이 그대로예요
- **타이머**: 행보드 리피터·맥스행·타바타
- **내 폰에만 저장**: 로그인이 없어요. 클립은 각자의 폰에만 저장되고 어디에도 올라가지 않아요. 남길 클립은 사진첩(갤러리)에 저장하세요.

## 설치

설치 파일 없이 웹으로 써요: `https://<GitHub 아이디>.github.io/betalog-app/`

| 기기 | 방법 |
|---|---|
| 아이폰 | **사파리**로 열고 공유 → **홈 화면에 추가**. 홈 화면에 추가해야 아이폰이 7일 뒤 데이터를 지우지 않아요. |
| 갤럭시 | **크롬**으로 열고 화면의 **홈 화면에 설치** 버튼(또는 ⋮ → 홈 화면에 추가). 삼성 인터넷은 메뉴 → 현재 페이지 추가 → 홈 화면. |

한 번 열어 두면 인터넷이 안 될 때도 열려요.

## 구조

```
frontend/   React + TypeScript (Vite) 웹 앱
.github/    웹(GitHub Pages) 자동 배포
```

## 개발

```bash
cd frontend && npm install && npm run dev        # http://localhost:5173
```

## 보안

- 서버가 없어요. 클립과 설정은 폰 안(브라우저 저장소)에만 있고 네트워크로 나가지 않아요.
- 웹 앱은 콘텐츠 보안 정책(CSP)으로 이 사이트의 코드만 실행하고, 다른 서버와는 통신하지 않아요(글꼴 제외).
